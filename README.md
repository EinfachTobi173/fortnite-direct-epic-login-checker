# EpicVM

Thank you for purchasing **EpicVM**.

## Installation

### 1. Run the Setup
1. Start `setup.exe`
2. Log in with your license key **or** create a new username and password and enter your license key
3. After setup is complete, run `auth.exe`

### 2. Start the Program
Launch `EpicVM.exe`. You will be logged in automatically.

## Antivirus Notice

The program may close unexpectedly or be detected as a virus by Windows Defender / your antivirus software.  
This happens because the code is obfuscated. Antivirus programs sometimes flag obfuscated software as a threat.

**This is a false positive.**  
You can safely add the program folder to your antivirus exclusions if needed.
